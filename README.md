## hello world !

I build software and AI tools, mostly multi-agent systems for healthcare. Currently working on AI agents for clinical workflows collaborating with [Histora](https://www.histora.com/). More at [lgarbayo.com](https://lgarbayo.com) ヅ

## Projects

- **[Agentic Smart Health](https://github.com/ANFAIA/Agentic-Smart-Health)**: multi-agent system that turns DICOM, STL and PDF dental data into a Gaussian Splatting digital twin. Built at ANFAIA ([🌐 site](https://agentic-smart-health.lgarbayo.com))
- **[PayPerPhase](https://github.com/lgarbayo/payperphase)**: dental treatment you pay for phase by phase with PayPal, on the day you receive it, never in advance. Claude turns the clinic's quote into a plan with healing windows. PayPal AI Hackathon 2026 ([🌐 app](https://payperphase.onrender.com/?lang=en) · [Devpost](https://devpost.com/software/payperphase) · [video](https://youtu.be/M7eus5cVwbo))
- **[Mecena](https://github.com/lgarbayo/mecena)**: AI agent that does the grant paperwork for artists and small businesses in Spain. It finds the calls you fit, drafts the application and scores it with a simulated jury. 1hack 2026 ([🌐 app](https://mecena.fly.dev) · [video](https://youtu.be/6f3wKt45Vrc))
- **[Taiafox](https://github.com/lgarbayo/HACKSPAIN-2026)**: crisis-response voice agent that replans resources in real time. HackSpain 2026 ([🌐 site](https://taiafox-ph-five.vercel.app/) · [Product Hunt](https://www.producthunt.com/products/taiafox))
- **[PeponBot](https://github.com/lgarbayo/pepon-bot)**: desktop robot built from an old Android phone, with local vision, speech and LLM reasoning
- **[jeicob](https://github.com/lgarbayo/jeicob)**: terminal research agent that finds, indexes and summarises scientific papers with RAG
- **[SEED Algorithm](https://github.com/lgarbayo/seed-algorithm)**: spatial optimisation that picks 1,000 elderly-care sites out of 36,000 census tracts. Fundación Innovación Bankinter
- **[MeigaSearch](https://github.com/lgarbayo/HackUDC-2026)**: document search engine with hybrid search and RAG chat with citations. HackUDC 2026 ([Devpost](https://devpost.com/software/meigasearch))
